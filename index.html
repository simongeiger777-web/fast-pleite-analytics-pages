Fast Pleite Analytics

Internes Auswertungs-Tool fuer den YouTube-Kanal "Fast Pleite". Liest ueber die YouTube Data API und die YouTube Analytics API ausschliesslich die eigenen Kanaldaten (Klickrate, Sehdauer, Views) des Kanalinhabers aus, zur internen Produktionssteuerung.

Keine oeffentliche Anwendung, kein weiterer Nutzerkreis.
